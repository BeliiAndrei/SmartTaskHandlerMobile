# Демонстрация QR для Lab 5

Печатайте [warehouse_b1_qr.png](warehouse_b1_qr.png) без обрезки белой рамки.
Векторный [SVG](warehouse_b1_qr.svg) подходит для печати в любом масштабе.
QR содержит ровно `STH-LOC-B1` — значение точки `locations.id = 3`
«Стеллаж B1» в локальной SQLite-базе `server/app.db`.

В этой рабочей копии подготовлены аккаунт `lab5.demo@smarttask.local` с паролем
`Lab5Demo2026!` и задача «Демо QR: перенос груза на стеллаж B1» (сейчас ID 1):
отправление — «Приёмка A1», назначение — «Стеллаж B1». В приложении войдите
этим аккаунтом, откройте задачу, выберите статус «Выполнена», сканируйте
распечатку и нажмите «Сохранить статус». Backend сравнит QR с точкой назначения.

База и загруженный файл находятся локально и игнорируются Git. Для повторной
подготовки на чистом клоне сначала запустите сервер из `server/` командой
`dotnet run`. Во втором PowerShell-окне из корня проекта выполните:

```powershell
python -m pip install --target .qrdeps -r tool/requirements-demo.txt
$env:PYTHONPATH = (Resolve-Path '.qrdeps').Path
python tool/prepare_lab5_demo.py
```

Скрипт повторно использует незавершённую демонстрационную задачу и уже
загруженный PNG. Он проверяет значение QR в `locations`, загружает PNG через
`POST /files` и проверяет записи задачи и файла в SQLite.

Для Android-эмулятора API доступен по `http://10.0.2.2:8080`. Для физического
телефона при запуске Flutter задайте адрес компьютера в той же сети через
`--dart-define=API_BASE_URL=http://<IP-компьютера>:8080`.
